# Sage - Service Oriented Architecture Project

This project contains the microservices and frontend applications for Sage.

## Project Structure

- `eureka-server/`: Service Registry (Spring Cloud Eureka Server)
- `config-server/`: Centralized Configuration Server
- `api-gateway/`: API Gateway
- `auth-service/`: Authentication and Authorization service
- `profile-service/`: User profile management service
- `calendar-service/`: Calendar and scheduling service
- `sage-brain/`: Core logic and intelligence service
- `notification-service/`: Notifications dispatcher service
- `frontend/`: Web user interface
